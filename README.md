# 🌆 London Explorer — AI-Powered Travel Guide & Chatbot

A full-stack web application that serves as an intelligent travel companion for London visitors. Built with a Node.js/Express backend, Google Dialogflow NLP, and Gemini AI for natural language responses.

🌐 **Live Site:** [mithun-ksms.github.io/london_tourism_chatbot](https://mithun-ksms.github.io/london_tourism_chatbot)

---

## ✨ Features

- 🤖 **Jojo AI Chatbot** — Powered by Google Dialogflow + Gemini AI. Answers questions about attractions, food, transport, safety, nightlife, and more
- 🌦️ **Live Weather** — Real-time London weather and 5-day forecast via OpenWeatherMap API
- 🚇 **Tube Status** — Live London Underground status via TfL API (no key required)
- 💷 **Currency Converter** — Convert 30+ currencies to GBP using live exchange rates
- 🗺️ **Interactive Map** — OpenStreetMap-powered map of central London
- 🗓️ **AI Itinerary Generator** — Personalised day-by-day London itineraries generated by Gemini AI
- 📸 **Attraction Details** — Info, opening hours, ticket prices and fun facts for key landmarks

## 🏗️ Architecture

```
GitHub Pages (Frontend)
    │
    │  HTTP requests (weather, itinerary, chatbot)
    ▼
Render (Backend — Node.js/Express)
    │
    ├── /api/weather        → OpenWeatherMap API
    ├── /api/forecast       → OpenWeatherMap API
    ├── /api/itinerary      → Gemini AI
    └── /webhook            → Dialogflow fulfillment → Gemini AI
```

The backend acts as a secure proxy — API keys are never exposed in the frontend code.

## 🚀 Running Locally

### Prerequisites
- Node.js v18+
- API keys for: OpenWeatherMap, Google Maps, TripAdvisor, Gemini

### Setup

```bash
# Clone the repo
git clone https://github.com/mithun-ksms/london_tourism_chatbot.git
cd london_tourism_chatbot

# Install dependencies
npm install

# Copy environment template and fill in your keys
cp .env.example .env

# Start the server
npm start
```

Server runs at `http://localhost:3000`

### Environment Variables

```
WEATHER_API_KEY=your_openweathermap_key
MAPS_API_KEY=your_google_maps_key
TRIPADVISOR_API_KEY=your_tripadvisor_key
GEMINI_API_KEY=your_gemini_key
```

- All API keys stored as environment variables on Render — never committed to git
- Backend acts as proxy so keys are never visible in browser source code
- `.gitignore` prevents accidental key exposure
